# SGit-AI__Website__Newsroom__2026__Oct__PHP__data

The data of [php.oct.2026.newsroom.sgit.ai](https://php.oct.2026.newsroom.sgit.ai/), the newsroom's site on the two
critical PHP flaws of October 2026 (CVE-2026-109618 and CVE-2026-109619, "php2shell"), published as immutable
versions at **https://data.php.oct.2026.newsroom.sgit.ai/**:

- `/v/<version>/<file>.json`: never changes once published; `/v/<version>/manifest.json` lists every file with its
  sha256, size and schema.
- `/latest/`: the newest version.
- `/versions.json`: every version, with what changed.

What is here: the evidence exported from the vaults (sources, the vault's claims and timeline, the software inventory,
the source watch, pulse, Wikipedia), the story's data (claims, timeline, actors, agencies, numbers, impact), the desk's
state of affairs and reviews, the fact-check, the risk graph and its history, and the ontology. Captures stay in the
evidence vault. The rules for working here are in [CLAUDE.md](CLAUDE.md).
